# Hook & Sell

A casual one-finger fishing game built for YouTube Playables.

Drop your hook, dodge the fish on the way down, grab everything on the way up, sell the catch and upgrade your gear, from the Mediterranean coast down to the Kraken in the abyss.

- Play: https://dvostt.github.io/hook-and-sell/
- Preview video: https://dvostt.github.io/hook-and-sell/preview.mp4

Single HTML5 file, no libraries or external assets, YouTube Playables SDK integrated, English and Italian.
